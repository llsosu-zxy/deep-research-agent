# Hugging Face Space Deployment

This folder documents how to deploy the Gradio demo to Hugging Face Spaces.

## Files needed at the Space root

- `hf_space_app.py` (the Space entry point)
- `requirements.txt`
- `data/corpus/seed/` generated by `python scripts/seed_corpus.py`

## Deploy steps

1. Create a new Gradio Space on Hugging Face.
2. Push this repository, keeping `hf_space_app.py` at the root.
3. Set the Space Python version to 3.12.
4. Set optional secrets for `LLM_PROVIDER`, `LLM_BASE_URL` and `LLM_API_KEY`.
5. The Space runs `hf_space_app.py` automatically on port 7860.

The default mock mode works on the free CPU tier; GPU accelerators are only
needed when switching to BGE-M3 embeddings, rerankers or LoRA fine-tuning.
